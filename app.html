Sign-in setup (Google)

Guest mode always works with zero setup. To let people sign in with a real Google account on your copy of this page, create a free OAuth Client ID and paste it here:

1) Go to Google Cloud Console → APIs & Services → Credentials. 2) Create an OAuth client ID of type Web application. 3) Under Authorized JavaScript origins, add the exact URL this page is hosted at (e.g. https://yourdomain.com — file:// pages can't use Google Sign-In, so host this file somewhere first, even a free static host). 4) Copy the generated Client ID and paste it below.
